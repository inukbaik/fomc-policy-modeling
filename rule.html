The Rule: How the Target Relates to the Economy (RQ1)

  • Show All Code
  • Hide All Code
  • View Source
NoteOriginal course-project chapter

This chapter is the course-project team’s original analysis, written by teammates and kept as submitted. The only changes are shared data fixes and small cleanups (computed instead of hardcoded dates, clearer names); the methods were not revised for this portfolio. Known limitations:

  • Possibly spurious levels regression. The target, inflation and unemployment behave like trending series (see the unit-root tests below), and regressing trending series on each other can show strong relationships that are not real. A partial-adjustment model (the lagged target as a regressor, used below only as a robustness check) is the standard way to estimate a policy rule.
  • Standard errors ignore autocorrelation. Monthly errors are strongly correlated over time, so the ordinary p-values overstate how certain each estimate is. Newey-West (autocorrelation-robust) errors would be wider.
  • Zero-lower-bound months are included. In 2009–2015 and 2020–2022 the target could not fall below zero, so it stayed flat whatever the economy did. Those months pull every estimated response toward zero.
  • Lasso screening. It is given core_pce_yoy and inflation_gap (the same series shifted by 2), uses random cross-validation folds on time-series data, and its result is not used afterwards.
  • Break tests reject everywhere. The Chow tests assume independent errors and reject stability at every date tested, and BIC selects the maximum number of breaks allowed, so neither pins down when the rule changed. The number of breaks is therefore a fixed setting.

This section studies how the federal funds target is related to selected macroeconomic and financial variables, and whether those relationships remain stable over time.

## Original course-project chapter

This chapter is the course-project team's original analysis, written by
teammates and kept as submitted. The only changes are shared data fixes
and small cleanups (computed instead of hardcoded dates, clearer names);
the methods were not revised for this portfolio. Known limitations:

- **Possibly spurious levels regression.** The target, inflation and
  unemployment behave like trending series (see the unit-root tests below),
  and regressing trending series on each other can show strong
  relationships that are not real. A partial-adjustment model (the lagged
  target as a regressor, used below only as a robustness check) is the
  standard way to estimate a policy rule.
- **Standard errors ignore autocorrelation.** Monthly errors are strongly
  correlated over time, so the ordinary p-values overstate how certain each
  estimate is. Newey-West (autocorrelation-robust) errors would be wider.
- **Zero-lower-bound months are included.** In 2009–2015 and 2020–2022 the
  target could not fall below zero, so it stayed flat whatever the economy
  did. Those months pull every estimated response toward zero.
- **Lasso screening.** It is given `core_pce_yoy` and `inflation_gap`
  (the same series shifted by 2), uses random cross-validation folds on
  time-series data, and its result is not used afterwards.
- **Break tests reject everywhere.** The Chow tests assume independent
  errors and reject stability at every date tested, and BIC selects the
  maximum number of breaks allowed, so neither pins down when the rule
  changed. The number of breaks is therefore a fixed setting.
:::

```{r}

abline(v = bp_dates, col = "red")
```

The analysis uses `r n_breaks` breaks, estimated at `r paste(format(bp_dates, "%b %Y"), collapse = ", ")`. BIC alone would pick `r bic_breaks`, the most the test allows; with trending variables and serially correlated errors BIC tends to over-select breaks, so the number of breaks is kept as an explicit choice.

## Chow Tests

```{r}
chow_dates <- sort(unique(c(CHOW_EVENT_DATES, bp_dates)))

for (d in as.list(chow_dates)) {
  idx <- which(df_reg_rq1$date == d)
  if (length(idx) > 0) {
    test <- sctest(rq1_formula, type = "Chow", point = idx, data = df_reg_rq1)
    cat("Date:", format(d),
        if (d %in% bp_dates) "(estimated break)" else "(event)",
        "| F =", round(test$statistic, 2),
        "| p-value =", format(test$p.value, scientific = TRUE), "\n")
  }
}
```

The Chow tests evaluate whether the regression relationship shifts at both estimated and theory-motivated break dates.

## Sub-Period Regressions

```{r}
# Sub-periods run between the estimated break dates.
period_starts <- c(min(df_reg_rq1$date), bp_dates)
period_ends   <- c(bp_dates, max(df_reg_rq1$date) + 1)
period_labels <- paste0(format(period_starts, "%Y"), "-", format(period_ends - 1, "%Y"))

df_reg_rq1$period <- cut(
  df_reg_rq1$date,
  breaks = c(period_starts, max(df_reg_rq1$date) + 1),
  labels = period_labels,
  right = FALSE
)

models <- lapply(period_labels, function(p) {
  lm(rq1_formula, data = subset(df_reg_rq1, period == p))
})
names(models) <- period_labels
```
