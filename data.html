This page builds the monthly dataset used by every chapter and explores it. The data are fetched from FRED and the Federal Reserve’s FOMC calendar by R/acquire_data.R; nothing is committed to the repository. The chapters are The rule (RQ1), The regimes (RQ2) and The prediction (RQ3).

Settings

Analysis choices in one place. Everything else (sample end, break dates, number of clusters) is computed from the data.

Code 
SAMPLE_START    <- as.Date("1986-01-01")  # start of the modeling sample
MAX_GAP_FILL    <- 1                      # fill internal gaps up to this many months
BP_MAX_BREAKS   <- 5                      # most structural breaks the test considers (RQ1)
BP_N_BREAKS     <- 3                      # breaks used (RQ1); BIC picks the max here, see C4
K_RANGE         <- 2:8                    # cluster counts shown in diagnostics (RQ2)
K_CLUSTERS      <- 3                      # clusters used (RQ2); silhouette is flat, see C5
LABEL_WINDOW_DAYS <- 2                    # days after a decision to read the new target (RQ3)
# Days after the end of month m by which month m's value is published.
# Cautious approximations of the usual release calendar; series not listed
# (market data, Michigan survey, oil, the target itself) are known by the
# end of month m. Real release dates (ALFRED) will replace this later.
RELEASE_DELAY_DAYS <- c(
  UNRATE   = 10,  # Employment Situation, first Friday of m+1
  PAYEMS   = 10,
  INDPRO   = 18,  # industrial production, mid m+1
  HOUST    = 20,  # housing starts, around the 17th-19th of m+1
  PCEPILFE = 31,  # personal income and outlays, end of m+1
  PCEPI    = 31
)
ZLB_MAX_TARGET  <- 0.25                   # target at or below this = zero lower bound (RQ3 feature)
# Inputs of the ordered probit and hazard models (RQ3), fixed in advance,
# Taylor-rule style: last decision, inflation, unemployment, market
# expectations, zero lower bound.
RQ3_TAYLOR_VARS <- c("prev_move", "inflation_gap", "UNRATE", "market_2y_spread", "at_zlb")
RQ3_START_TRAIN <- 200                    # meetings in the first training window
RQ3_STEP        <- 12                     # meetings per test block
RQ3_ROLLING_WINDOW <- 120                 # meetings in the rolling-window check (~15 years), fixed in advance
RQ3_WEIGHT_OPTIONS <- c(FALSE, TRUE)      # tuning tries unweighted and inverse-frequency class weights (RQ3)
RQ3_SEED        <- 597                    # seed for model fitting and the bootstrap (RQ3)
RQ3_BOOT_REPS   <- 1000                   # bootstrap resamples for score intervals (RQ3)
RQ3_CORES       <- max(1, parallel::detectCores(logical = FALSE) - 2)  # parallel folds (1 on Windows)
RQ3_BOOT_BLOCK  <- 8                      # meetings per bootstrap block (~1 year)

# Events tested with Chow tests alongside the estimated break dates (RQ1)
CHOW_EVENT_DATES <- as.Date(c(
  "2001-09-01",  # 9/11
  "2008-01-01",  # start of 2008 easing
  "2008-11-01",  # zero lower bound reached
  "2020-03-01"   # COVID
))

The raw dataset has 0 duplicate rows and covers 1982-09-01 to 2026-11-01. The main issue is missingness: series that start later (DTWEXBGS, T5YIE, JTSJOL, JTSQUR, RRSFS) are missing for more than 20% of months, and the most recent months are incomplete because of publication delays. These are handled in the cleaning steps below.

Handle Missing Values

Code 
# Fill short gaps inside a series (e.g. October 2025, when the government
# shutdown stopped some releases) by carrying the last value forward.
# Carrying forward never uses later data, so it adds no look-ahead.
# Leading NAs (before a series starts) are left alone.
before <- df_clean

df_clean <- df_clean %>%
  arrange(date) %>%
  mutate(across(
    all_of(series_cols),
    ~ zoo::na.locf(.x, na.rm = FALSE, maxgap = MAX_GAP_FILL)
  ))

filled <- map_dfr(series_cols, function(col) {
  idx <- which(is.na(before[[col]]) & !is.na(df_clean[[col]]))
  tibble(series = col, date = before$date[idx], filled_with = df_clean[[col]][idx])
})

Feature Engineering

Create Derived Variables

Code 
df_clean <- df_clean %>%
  arrange(date) %>%
  mutate(
    core_pce_yoy      = 100 * (PCEPILFE / lag(PCEPILFE, 12) - 1),
    unrate_lag1       = lag(UNRATE, 1),
    payems_yoy        = 100 * (PAYEMS / lag(PAYEMS, 12) - 1),
    term_spread_10y_3m = DGS10 - DGS3MO,
    inflation_gap     = core_pce_yoy - 2
  )

Several derived variables were created to better capture macroeconomic conditions relevant to policy decisions, including core inflation growth, lagged unemployment, payroll growth, the term spread, and the inflation gap relative to the 2 percent target.

Create Target-Related Variables

Code 
# Produced by R/acquire_data.R. Keep meetings and conference calls; drop
# notation votes and the cancelled March 2020 meeting. `date` is the first day
# of the meeting, as in the original fed_meetings.csv.
fomc_meetings <- read.csv("data/fomc_meetings.csv") %>%
  filter(!type %in% c("cancelled", "notation_vote")) %>%
  mutate(date = as.Date(start_date))

fomc_monthly <- fomc_meetings %>%
  mutate(month = as.Date(format(date, "%Y-%m-01"))) %>%
  group_by(month) %>%
  summarise(
    fomc_meetings    = n(),
    fomc_scheduled   = sum(is_scheduled, na.rm = TRUE),
    fomc_unscheduled = sum(!is_scheduled, na.rm = TRUE),
    .groups = "drop"
  )

df_clean <- df_clean %>%
  mutate(month = as.Date(format(date, "%Y-%m-01"))) %>%
  left_join(fomc_monthly, by = "month") %>%
  mutate(
    fomc_meetings    = dplyr::coalesce(fomc_meetings, 0),
    fomc_scheduled   = dplyr::coalesce(fomc_scheduled, 0),
    fomc_unscheduled = dplyr::coalesce(fomc_unscheduled, 0)
  )

Monthly FOMC meeting counts were merged into the main dataset so the analysis could distinguish between months with scheduled meetings, unscheduled meetings, and no meetings.

Code 
fomc_dates <- fomc_meetings %>%
  arrange(date)

df_clean <- df_clean %>%
  rowwise() %>%
  mutate(
    days_since_last_fomc = as.numeric(date - max(fomc_dates$date[fomc_dates$date < date]))
  ) %>%
  ungroup() %>%
  select(-month)

The variable days_since_last_fomc was added to measure how much time had passed since the most recent FOMC meeting, providing a simple timing feature related to policy activity.

Key EDA Findings

Overall, the exploratory analysis showed that the dataset is time-ordered and contains variables that vary meaningfully across different monetary policy environments. The federal funds target displays clear changes over time rather than a uniform distribution, and several predictors appear to move in related patterns. The correlation analysis also suggests that some variables are highly related, which supports paying attention to multicollinearity and model flexibility in the later modeling stage.

```{r}
most_missing <- names(na_share[na_share > 0.2])
```

The raw dataset has `r sum(duplicated(df_raw))` duplicate rows and covers `r format(min(raw_dates))` to `r format(max(raw_dates))`. The main issue is missingness: series that start later (`r paste(most_missing, collapse = ", ")`) are missing for more than 20% of months, and the most recent months are incomplete because of publication delays. These are handled in the cleaning steps below.

# Data Cleaning

## Fix Variable Types

```{r fix-types}
```

The date variable was converted to `Date` format so the dataset could be filtered, joined, and ordered consistently in later preprocessing steps.

## Remove Invalid or Incomplete Observations

```{r sample-end}
```

The sample ends in `r format(SAMPLE_END, "%B %Y")`, the last month in which every series has been published. Later months are dropped because some series are released with a delay of one to two months.

## Handle Missing Values

```{r fill-gaps}
```

`r nrow(filled)` value(s) were missing inside a series and filled with the previous month's value: `r paste(filled$series, format(filled$date, "%b %Y"), collapse = ", ")`.

Oil prices come from `WTISPLC`, the monthly WTI spot price, which has a longer history than the daily series.

# Feature Engineering

## Create Derived Variables

```{r derived}
```

Several derived variables were created to better capture macroeconomic conditions relevant to policy decisions, including core inflation growth, lagged unemployment, payroll growth, the term spread, and the inflation gap relative to the 2 percent target.

## Create Target-Related Variables

```{r fomc-counts}
```

Monthly FOMC meeting counts were merged into the main dataset so the analysis could distinguish between months with scheduled meetings, unscheduled meetings, and no meetings.

```{r fomc-timing}
```

The variable `days_since_last_fomc` was added to measure how much time had passed since the most recent FOMC meeting, providing a simple timing feature related to policy activity.

```{r final}
```

After preprocessing and feature construction, the final working dataset was restricted to the post-1986 period to align with the availability of the selected variables and the scope of the modeling analysis.
