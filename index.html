How Does the Fed Set Rates, and Can We Predict Its Next Move?

Eight times a year the Fed decides to cut, hold or raise interest rates. This project predicts that decision using only information available before each meeting.

Key results

  • The best models score 0.71 (macro-F1) on 126 meetings since 2010, against 0.65 for simply repeating the last decision. The gap is too small to be sure it is real.
  • What helps most is information about the Fed itself: its last decision, where rates are, and what markets expect.
  • A simple six-input model built for policy decisions does as well as the best machine-learning model.

About this project

This began as a group project for a graduate Statistical Computing course in spring 2026, built with my teammates Asal D. and Zihong X. I later came back to it to fix the limitations we had at the time: meeting labels that were often wrong, an evaluation that rewarded always predicting “hold”, and predictors that used data before it was published. I then extended the prediction chapter with new features and dynamic models. Every change and its effect is documented in What changed, and the original submission is kept as v1.0-course-submission.

Thanks to Asal and Zihong for the original work, including The rule and The regimes chapters.

```{r}
#| include: false
# Headline numbers come from the Prediction page, which writes them when it
# renders (_quarto.yml renders it before this page).
summary_file <- "results/rq3_summary.rds"
has_results  <- file.exists(summary_file)
if (has_results) {
  rq3 <- readRDS(summary_file)
  rk  <- rq3$ranking
  fitted  <- rk[!startsWith(rk$Model, "Baseline_"), ]
  n_clear <- sum(fitted$Gap_low > 0)
  hazard_f1 <- rk$Macro_F1[rk$Model == "Hazard_Two_Step"]
  best_ml_f1 <- rk$Macro_F1[endsWith(rk$Model, "_Tuned")][1]
}
```
